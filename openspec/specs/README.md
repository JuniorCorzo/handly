# Specs — source of truth

Main specs live here after the first archived change merges its deltas.

Layout:

```
openspec/specs/{domain}/spec.md
```

Domains align with the product proposal (`docs/PROPUESTA_ARQUITECTURA.md`):
`zones`, `organizations`, `need-items`, `pledges`, `triage-ai`, `portal`, `acopio`.

Until the first change is archived, this directory is intentionally empty.
Each active change keeps its delta specs at `openspec/changes/{change-name}/specs/{domain}/spec.md`.
